## What's New

- **Export to PDF.** Turn any presentation into a PDF straight from the app — the `File > Export PDF…` menu item (or the same entry in the slide-card menu) renders every slide as its own page at glorious resolution and saves it through the native save dialog.
- **Check for Updates.** A new `Help > Check for Updates…` entry compares your build to the latest GitHub release and, when a newer version exists, shows what's new and links straight to the download. It also pings quietly a few seconds after launch, so you only hear about it when there is an update.
- **About dialog.** `Help > About DevSlides` shows the running version, the project description and one-click links to the repository and issue tracker. Version is read from the backend, so it can't drift from the crate.
- **Help menu.** Keyboard shortcuts, documentation and "Report an Issue" are now first-class entries in the native Help menu on every platform.
- **Image panel on the right.** The image-manipulation panel docks on the right edge of the editor, matching the workflow of adding and tweaking image layers next to the slide list.

## Changes

- The update check runs in Rust (the webview CSP blocks outbound HTTP), fetching the latest GitHub release with a short timeout; offline or failed checks stay silent at startup and only report when you ask.
- PDF export reuses the existing per-slide render path, so exports match what you see — colors, highlights, transitions and images included.
- macOS keeps its dedicated app-menu section; the extra Help entries stay available on Windows and Linux too.

## Fixes

- Minor styling and spacing polish in the image panel.
