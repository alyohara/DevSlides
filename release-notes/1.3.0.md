## What's New

- **Images in slides.** Every slide can now carry image layers:
  - **Background images** fill the whole stage behind the code.
  - **Element images** are placed anywhere on the stage, sized, and stacked above the code.
  - **Image-only slides** are just a background image with no code.
- **Two ways to add images:** pick a file with the native dialog (PNG, JPEG, GIF, WebP, BMP, AVIF) or paste straight from the clipboard.
- **Drag on the canvas.** Select an image layer and drag it around the preview, or use the corner handle to resize it. Position, size, opacity, z-order, and role (element/background) are also editable from the image panel.
- **Fully portable projects.** Images are embedded as base64 data URLs inside the project, so export/import and sharing keep every image intact.

## Changes

- This is the first release of the [alyohara](https://github.com/alyohara) fork of OpenSlides, built on top of the upstream 1.2.3 codebase. Upstream remains the source of the original code-preservation features; images are new in this fork.
- Release automation mirrors the upstream pipeline: multi-platform builds (macOS Apple Silicon and Intel, Windows x64 and ARM64, Linux deb/rpm/AppImage) are published on a `v*` tag push.
